# IndiaBUILD verified “How it works” observations

URL: https://indiabuild.wiki/how-it-works

The page defines four layers: sector → capability → foundational capabilities → builders. A capability can be a finished product or a foundational element; the distinction is positional in the dependency chain. The example is a large narrowbody jet resting on a turbofan engine, certified avionics, and fatigue testing, with each foundation having its own lower-level tech tree.

The page defines six capability statuses: No capability, Emerging, Demonstrated, Producing (licensed), Producing (own tech), and Competitive. It defines a separate builder ladder: Study → R&D → Prototype → Testing → Certification → Limited production. For each capability the site shows both what a builder claims and the site’s own assessment from evidence. A capability with no builders is explicitly shown as an open opportunity.

The page is direct evidence for Forge World’s proposed conceptual primitives: hierarchical capability nodes, directed dependency/unlock edges, maturity states, builder attempts, claim-versus-assessment separation, and open gaps. It does not by itself establish production capacity, cost, lead time, yield, or geographic facility data; those must be added from other sources.
